Google Sheet Sync

Every time a student clicks Reserve equipment, this page can send that booking — with a timestamp — straight into your Google Sheet. It connects through a small Google Apps Script attached to the sheet, one-time setup:

  1. Open your spreadsheet → Extensions → Apps Script
  2. Delete any starter code, paste in the script provided separately
  3. Click Deploy → New deployment → Web app
  4. Set "Execute as" to Me and "Who has access" to Anyone
  5. Deploy, authorize it, then copy the Web app URL it gives you
  6. Paste that URL below and save
